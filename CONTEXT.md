# Rules

This document outlines core instructions, constraints, and guidelines for development within the Wadiolk repository.

## Formatting & Output Rules

### Emoji Policy
- **DO NOT** use any emojis in terminal outputs, error traces, warnings, success banners, comments, or commit messages.
- Use uppercase tags (e.g., `[ERROR]`, `[WARN]`, `[SUCCESS]`, `[INFO]`) along with ANSI colors to display status levels instead of visual emojis. Keep terminal and file environments entirely clean, professional, and text-only.

## Maintenance & Documentation Rules

### Skill & Documentation Sync
- **Skills Documentation Sync**: Whenever skills in `skills/` are created, updated, or removed, [README.md](file:///Users/adiwu/myrepo/skills/README.md) MUST be updated immediately to reflect the latest Directory Structure and Available Skills list.
